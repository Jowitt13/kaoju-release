# kaoju v0.4.1

为 Agent 提供多源搜索、论文检索、网页采集与图文检索能力的 Windows 发行版

## 下载与安装

- **联网安装器：`kaoju-setup-0.4.1.exe`**。单个 EXE，运行后从本仓库下载并校验固定版本发行包，再进入安装向导。安装采集扩展时仍可能需要联网获取依赖和浏览器
- **离线安装器：`kaoju-setup-0.4.1-offline.exe`**。单个 EXE，内置固定版本运行组件、采集依赖和浏览器资源。离线安装不代表搜索和网页采集可以脱离网络使用
- `kaoju-0.4.1.zip` 是联网入口下载的运行发行包，不是另一个必须手动下载的安装步骤
- 本版未做代码数字签名。安装前请核对下载来源及随附 SHA-256；不要关闭系统安全防护

## 四个搜索场景

安装目录包含四个完整场景及其支持文件，Agent 接入页面可复制接入提示词和场景任务

| 场景 | 用途 |
| --- | --- |
| 论文研究 `kaoju-paper` | 查找论文与研究脉络，比较方法、观点和研究空白 |
| 竞品调研 `kaoju-compete` | 搜索官方产品信息与用户反馈，比较定位、功能和差异 |
| 建筑案例 `kaoju-arch` | 检索建筑作品、案例页面和参考图，比较空间与设计策略 |
| 舆情动态 `kaoju-watch` | 按需检索近期信息、整理时间线和变化，不内置定时监测或自动通知 |

MCP 的九个工具可用不等于客户端已经加载 Skills。请使用安装器生成的接入提示词，保留其他服务及模型设置，分别验证 MCP 连接和场景发现；不支持原生 Skills 的客户端可使用手动场景任务

## 本版交付

- 联网、离线入口均固定为 v0.4.1，并绑定对应发行包大小与 SHA-256
- 两种安装方式使用同一套重新编译的运行组件
- 保留雕塑视觉、中文宋体风格、固定尺寸向导及 Agent 接入入口
- 保留九个 MCP 工具及四场景的完整目录与建筑模板
- 下载、文件校验、安装失败、降级与取消清场分别处理，不以复制配置替代真实连接验证
- 不自动覆盖既有客户端配置；安装完成后按向导提示接入 Agent
